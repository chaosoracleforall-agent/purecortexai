# Immunefi Submission Runbook

Use this runbook with `docs/IMMUNEFI_BOUNTY_SPEC.md` to publish the bounty listing.

## Submission Steps
1. Open [Immunefi](https://immunefi.com/) and sign in with the PURECORTEX owner account.
2. Start a new bounty listing and copy content from `docs/IMMUNEFI_BOUNTY_SPEC.md`.
3. Confirm in-scope assets include:
   - Smart contracts (`contracts/smart_contracts/*`)
   - Backend API and signer flows (`backend/*`)
   - Mainnet infrastructure and deployment scripts (`scripts/*`, `docker-compose.yml`, nginx)
4. Set disclosure policy and payout bands exactly as defined in the spec.
5. Submit for review and record:
   - Submission timestamp
   - Listing URL
   - Any required edits from Immunefi review
